CSS Box Model Practice

Every HTML element can be understood as a box made up of content, padding, border, and margin.

Box One: content-box

Content-box

Width: 300px, plus padding and border.

With content-box, the declared width applies to the content. Padding and borders increase the total width.

Box Two: border-box

Border-box

Maximum total width: 300px.

With border-box, the declared width includes content, padding, and borders. This makes responsive layouts easier.

Box Model Properties

  • Content: The text or image inside.
  • Padding: Space inside the border.
  • Border: The line surrounding the padding.
  • Margin: Space outside the border.
