## Lessons Learned

### 1. The CSS Box Model

I learned that the total size of an element depends on its content,
padding, borders, and margins. I used `box-sizing: border-box`
to make element sizing easier to manage.

### 2. CSS Custom Properties

I learned to store colours, typography sizes, spacing, and other
reusable values in `:root`. This makes it easier to maintain a
consistent design and update the site.

### 3. Flexbox

I used Flexbox to align the navigation links, arrange the hero
section, and organize the footer content. I also used `flex-wrap`
to help prevent navigation items from overflowing.

### 4. CSS Grid

I used CSS Grid for the projects page. The layout changes from
one column on phones to two columns on tablets and three columns
on desktop screens.

### 5. Mobile-First Design

I learned to write the basic styles for smaller screens first and
then use `@media (min-width: ...)` to improve the layout on larger
screens.

### 6. Keyboard Accessibility

I added `:focus-visible` styles so keyboard users can see which
link, button, or form control is focused. I also used labels and
descriptive alternative text for images.
